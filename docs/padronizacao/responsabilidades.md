# Responsabilidades

| Participante | Responsabilidades |
| --- | --- |
| Desenvolvedor | Criar a branch correta; desenvolver a tarefa; usar commits padronizados; testar localmente; criar a PR; preencher o template; corrigir problemas encontrados na revisão. |
| CI | Executar testes; validar build; detectar falhas automaticamente; fornecer as verificações obrigatórias que, com a proteção da branch configurada, impedem a integração em caso de falha. |
| Sonar | Analisar qualidade; identificar possíveis bugs, vulnerabilidades e code smells; verificar as métricas configuradas; validar o Quality Gate. |
| CodeRabbit | Auxiliar a revisão; analisar alterações da PR; identificar possíveis problemas e sugerir melhorias. |
| Revisor humano | Analisar a implementação; avaliar a aderência à tarefa, à arquitetura e às regras do projeto; aprovar ou solicitar alterações; autorizar a integração. |

A revisão automatizada auxilia a equipe. A aprovação humana continua obrigatória
e a decisão final sobre a integração pertence à equipe.
